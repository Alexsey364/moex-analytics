# Predictive data source matrix

Каталог predictive_data_catalog разделяет официальный endpoint, частоту, timezone, правило
available_from, лицензию, PIT status и eligibility. Исторические веса индексов, ticks/orderbook,
consensus, news archive и fund flows не заменяются синтетическими рядами. Значения индексов
можно использовать отдельно от их платной исторической структуры.
