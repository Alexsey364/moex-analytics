# Visual Predictive Command Center

Stage 48 adds the BASIC page **«Прогноз рынка и моих акций»** and Advanced **Historical Analog Explorer 3.0**. Both pages are read-only consumers of stored Stage 43–47 results; rendering performs no fitting, analog search or forecast calculation.

The BASIC view shows current regime familiarity, an accessible text-and-color portfolio horizon map, explicit shadow/abstention state, stored evidence and the historical trajectory fan. The explorer exposes instrument and similarity-method selection, actual top analog episodes, why-similar/why-different decomposition, observed paths normalized to T0=100 and terminal outcome distributions.

Fan bands describe how historical episodes evolved and are never labelled as a future price path or target. Green/red/yellow/gray always include arrows or text. Probability remains hidden and production logic remains unchanged.
