# Explainable SBER Decision Engine

Десять независимых блоков оцениваются отдельно. Иерархия сначала проверяет данные и критические риски, затем качество, valuation, technical и режим. Один непрозрачный средний балл не используется. Конфликт фундаментала и technical показывается и снижает confidence. Rejected macro сохраняется как evidence `rejected_excluded` с нулевым влиянием.

Статус — результат текущих правил, не BUY/SELL и не гарантия. Текст формируется детерминированными шаблонами без LLM.
