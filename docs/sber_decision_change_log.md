# Decision change log

Лог хранит решение до и после события, изменённые блоки, параметры и зоны. Текстовая гипотеза никогда не меняет параметры автоматически. Автоприменение допустимо только для validated числового официального факта с прямой связью с SBER; остальные adjustments требуют ручного подтверждения.
