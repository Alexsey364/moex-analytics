# Проверка макромодели

Сравниваются безусловное среднее, technical, macro и combined. Expanding walk-forward обучается
только на прошлом и тестируется на следующем блоке без shuffle. Границы и отдельный untouched
holdout находятся в YAML. Версия `technical-v1` и старый out-of-sample не перенастраиваются.

Для доходности сохраняются MAE, RMSE, корреляция, rank correlation и точность знака. Код также
содержит метрики направления: accuracy, balanced accuracy, Brier score и log loss. Улучшение
считается подтверждённым только при превосходстве технической модели на holdout; единичный результат
чуть выше 50% недостаточен.

Главные ограничения: четыре российских инструмента, меняющаяся рыночная структура, неполная
история подтверждённых релизов CPI, отсутствие лицензированного PIT-safe внешнего рынка и
отсутствие исторической базы ожиданий решений ЦБ. Поэтому слой остаётся экспериментальным.
