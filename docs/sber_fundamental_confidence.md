# Confidence фундаментальных данных

Confidence — не вероятность правильного прогноза. Data confidence складывается из полноты,
свежести, числа релизов и лет истории, consistency checks, наличия РСБУ/МСФО и данных по акциям,
стабильности методологии. Ручные значения и неоднозначности дают штраф. Компоненты сохраняются
отдельно; valuation confidence и backtest confidence дополнительно понижаются при слабой базе.
