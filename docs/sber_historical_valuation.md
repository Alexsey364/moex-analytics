# Историческая фундаментальная оценка SBER

На следующую торговую дату после релиза вычисляются EPS, BVPS, ROE, P/E и P/B. В expanding-window
оценке медианы мультипликаторов формируются только из предыдущих релизов. Проверяются горизонты
20, 60, 120 и 250 торговых дней на общей выборке с naive current price. Сценарии текущей оценки
начинаются с validated прибыли/капитала, а YAML хранит только прозрачные корректировки.

РСБУ-режим 2018+ считается строго сопоставимым в рамках официальных форм; 2021 имеет архивный
разрыв. Периоды до 2018 остаются `requires_manual_review`. МСФО не смешивается с РСБУ.
