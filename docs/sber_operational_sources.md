# Операционные источники SBER

Разрешены только Банк России, официальный сайт и Investor Relations Сбера, Центр раскрытия,
MOEX. Каталог хранит URL и результат проверки отдельно от наблюдений. Discovery не валидирует
значения. Формы 101/102/806/807 требуют документа, даты публикации, available_from, revision и
версии методологии. Агрегаторы запрещены. Текущий pipeline может повторно использовать лишь
ранее validated факты официальных документов.
