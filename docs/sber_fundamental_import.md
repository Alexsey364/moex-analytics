# Контролируемый импорт SBER

Автоматически обрабатываются только структурированные HTML-таблицы Банка России. Файл хешируется
SHA-256; повторный URL и revision не создают новый документ. Сохраняются URL, локальный raw-путь,
заголовок, период, консервативная дата доступности, parser version и статусы.

Шаблон `data/templates/sber_fundamentals_import_template.xlsx` предназначен для значений из
официальных XLSX/PDF. В модель входят только строки `verification_status=validated`. PDF сначала
проверяется на текстовый слой, заголовки, период и единицы; OCR не является подтверждением.
Персональный заполненный review-файл и официальный raw-документ не коммитятся.
