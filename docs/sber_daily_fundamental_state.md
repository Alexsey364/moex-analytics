# Daily fundamental state

`sber_daily_fundamental_state` строится для торговых дат строго из релизов, доступных на соответствующую дату. Хранятся последний период МСФО и РСБУ, TTM/annualized показатели, EPS/BVPS, trailing и experimental forward multiples, dividend yield, возраст и confidence. Forward P/E помечен experimental. Годовая оценка применяется преимущественно к 120/250 сессиям, а не к следующему дню.
