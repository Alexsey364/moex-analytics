# Методология оценки SBER

P/E-модель: `forecast EPS × target P/E`. P/B–ROE использует BVPS и либо заданный P/B, либо
`(ROE − g) / (cost of equity − g)` при `cost of equity > g`. Дивидендная модель использует
`D1 / (cost of equity − g)` только при устойчивом знаменателе.

Cost of equity задаётся диапазоном сценариев: безрисковая ставка + beta × рыночная премия +
страновая премия + явная дополнительная премия. Это допущения, а не наблюдаемая точная величина.

P/E, P/B, dividend yield и earnings yield должны использовать только фундаментальный период,
доступный на дату цены. Справедливая стоимость — диапазон результатов независимых методов.
Высокая прибыль не гарантирует рост акции: цена также отражает риск, ставку дисконтирования,
ожидания, устойчивость прибыли и уже заложенную оценку.
