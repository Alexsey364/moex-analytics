# Прогнозные диапазоны

Диапазоны строятся из прогноза простой Ridge-модели и эмпирического распределения её ошибок.
Показываются центральные интервалы 50%, 80% и 90%. Если combined-модель не превосходит technical
на нетронутом holdout по RMSE, используется безусловное историческое распределение и модель
помечается как неподтверждённая.

Ценовые границы равны последней цене, умноженной на `(1 + граница доходности)`. Это
«исторически оценённый диапазон при текущей модели», а не обещание цены и не торговая рекомендация.
