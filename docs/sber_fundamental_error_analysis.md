# Анализ ошибок фундаментальной оценки SBER

Хранятся MAE, MAPE, ошибка доходности, направление и попадание в диапазон для каждой даты и модели.
Сводки разделяются на pre-2014, 2014–2021, 2022–2023 и holdout 2024+. Если период пуст, результат
показывается как недостаточный, а не переносится из другой эпохи. Historical error описывает прошлую
выборку и не гарантирует будущую точность; сценарии не донастраиваются после просмотра holdout.
