# Early-warning indicators

Положительные и отрицательные индикаторы сохраняются раздельно и не гасят друг друга.
Поля включают value, threshold, baseline, trend, severity, confidence, source/date и объяснение.
Порог допустим только из исторического распределения либо нормативного ограничения. При
недостаточной истории создаётся предупреждение о покрытии, а не числовой сигнал.
