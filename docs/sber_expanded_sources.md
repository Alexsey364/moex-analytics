# Расширенные источники SBER

Используются только официальные публикации Sber Investor Relations, документы эмитента MOEX, Центр раскрытия Интерфакс и формы Банка России. Поиск начинается с 1997 года. Документы сохраняются даже при частичной сопоставимости, но автоматически участвуют в расчёте только со статусом `validated`. МСФО и РСБУ никогда не объединяются в один ряд.

Каждое значение связано с документом, периодом, страницей/таблицей, датой публикации, `available_from`, единицей, revision и validation status. Отсутствие validated МСФО явно снижает confidence.
