# Point-in-time фундаментал SBER

Дата периода описывает экономический интервал, дата публикации — момент появления информации.
Значение доступно только с `available_from`. Snapshot торгового дня выбирает последнюю ревизию,
которая была опубликована к этому дню; поздняя ревизия не изменяет прошлые snapshots.

РСБУ и МСФО сохраняются отдельно. РСБУ чаще и отражает юридическое лицо, МСФО — группу; прямое
сложение или подмена запрещены. TTM строится только из четырёх неперекрывающихся кварталов одного
стандарта. Annualization явно маркируется и не заменяет TTM. EPS использует weighted average shares
соответствующего периода; BVPS — капитал и число акций одной даты.

Пропуски не заполняются. Возраст отчёта считается от конца периода, а источник и период переносятся
в snapshot для аудита. Рекомендация дивиденда доступна с даты публикации рекомендации, утверждённый
дивиденд — только с даты решения собрания.
