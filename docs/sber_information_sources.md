# SBER information sources

Приоритет имеют официальные Sber/IR, Центр раскрытия, MOEX ISS, Банк России и государственные органы. Хранятся только метаданные, числовые факты и ссылки; полные тексты новостей не копируются. Факт отличается от мнения validation status и источником. Вторичные сообщения допустимы лишь со ссылкой на первичный документ.
