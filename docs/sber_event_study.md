# Event study

Минимальные дневные окна: сессия, следующая сессия, 1/3/5/20/60 дней. Рассчитываются SBER, IMOEX и abnormal return, drawdown и confounding status. Финансовый индекс остаётся NULL, пока отсутствует надёжный point-in-time ряд. Корреляция по времени не доказывает причинность; общий рынок и события того же дня перечисляются как смешивающие факторы.
