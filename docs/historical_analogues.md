# Исторические аналоги

Состояния сравниваются по стандартизированным доходностям, расстояниям до SMA, волатильности, просадке, относительной силе и положению в годовом диапазоне. Используется объяснимое евклидово расстояние. Forward returns не участвуют в поиске. Жадный фильтр оставляет между аналогами минимум 20 торговых сессий, чтобы одно движение не дублировалось.

Для исходов показываются размер выборки, среднее, медиана, квартили, лучшие/худшие значения, просадки, интервал Уилсона и bootstrap-интервал медианы. «Историческая частота положительного исхода среди похожих состояний» не является гарантированной вероятностью. Предупреждения отмечают малую, сосредоточенную или зависимую от экстремумов выборку.
