# Формы 101 и 102

Pipeline: discovery → download raw → parser → mapping → units → validation → revisions →
point-in-time publication. Таблица cbr_form_metric_mapping версионирует line_code, column_code,
единицу и интервал действия. Разные эпохи не объединяются молча. На этапе 10 каталог форм
создан, но строки без подтверждённого официального документа не считаются наблюдениями.
