# Методология режима рынка

Режим IMOEX определяется прозрачными правилами из `config/settings.yaml`: положением относительно SMA50/SMA200, наклоном SMA200, доходностью 20/60 сессий, волатильностью и текущей просадкой. Классы: устойчивый/умеренный рост, боковой рынок, умеренное/устойчивое снижение, стресс и восстановление. Причины и фактические значения сохраняются для каждой даты. Ширина рынка пока не используется из-за выборки всего из четырёх инструментов. Будущие данные правилам недоступны.
