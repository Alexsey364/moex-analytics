# Макрофакторы

Для безопасных валютных, процентных, долговых и отраслевых рядов рассчитываются изменения за
1/5/20/60/120 сессий, волатильность и расстояние до SMA20/60/250. Процентный блок содержит
изменения ставки, реальную ставку только при наличии опубликованного CPI и спред RUONIA к ключевой
ставке. Отраслевой блок предусматривает относительную силу акции к сектору, сектора к IMOEX,
beta и корреляцию.

Наборы хранятся отдельно по горизонтам 1/5/20/60/120/250. В JSON источников сохраняется дата
исходного наблюдения. Корреляция не означает причинность: экономически правдоподобный фактор не
считается полезным, пока не улучшит walk-forward результат.
