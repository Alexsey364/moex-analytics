# Аудит ценовых зон SBER

При decision confidence около 50,9% слово «сильная» не подтверждено исторически. Поэтому
240–345 называется потенциально привлекательной зоной при подтверждении данных, 345–395 —
допустимой зоной первой покупки. Нижняя граница 240 означает повторную проверку предпосылок,
а не автоматически негативный сигнал. Границы остаются experimental до point-in-time проверки.
