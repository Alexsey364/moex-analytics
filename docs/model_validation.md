# Проверка информационной ценности

Статусы исторически вычисляются из признаков, доступных на соответствующую дату, и затем сопоставляются с отдельными forward returns на 20/60/120 сессий. Периоды development, validation и финальный out-of-sample заданы в YAML. Веса нельзя менять после просмотра out-of-sample. Версия и хеш параметров сохраняются в `analytics_runs`.

По статусам сравниваются размер выборки, средняя/медианная доходность, частота положительных исходов и будущая просадка. Это проверка информационной ценности, не бэктест торговой стратегии. Четыре инструмента, смены торговых режимов, качество ранней истории и отсутствие point-in-time дат объявления дивидендов существенно ограничивают выводы.
