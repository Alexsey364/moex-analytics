# Point-in-time макроданные

`observation_date` описывает период показателя, `release_date` — день публикации, а
`available_from` — первый допустимый момент использования. As-of join выполняется только по
`available_from <= cutoff`. Поэтому январский CPI не может появиться в январских признаках, если
он опубликован в феврале.

Предусмотрены cutoff следующего открытия и следующего закрытия в часовом поясе Москвы. Закрытие
зарубежного рынка после MOEX нельзя использовать для текущего закрытия MOEX. RUONIA из-за
неизвестного исторического времени релиза допускается только со следующего дня. Forward-fill
никогда не пересекает границу публикации назад.

Текущие архивы ЦБ и MOEX не являются полноценными vintage-базами. Это ограничение сохраняется в
метаданных и отчёте качества; серии без подтверждённых release dates не участвуют в строгом тесте.
